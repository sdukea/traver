# Traver

Interactive, animated study tool for binary tree and linked list traversals: pre-order, in-order, post-order and level-order.

- **Visualise** – step through each traversal with live code (Python, Java, C++), call stack or queue, and output.
- **The Trick** – the outline method: complete the tree with empty edges, then trace once around it to read off all three orders. Includes a practice mode.
- **Practice** – tap-the-order, name-the-traversal and rebuild-from-two-orders questions.
- **Cheat Sheet** – rules, uses, complexity and common exam traps.

It's a single static `index.html` with no build step. Open it in a browser or serve it with GitHub Pages.
